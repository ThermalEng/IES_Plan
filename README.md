# IES Plan

综合能源系统（Integrated Energy System, IES）规划软件。

项目已回到重新规划阶段。当前仓库仅保留产品目标，不预设技术栈、系统架构和开发路线。

## 产品目标

帮助小型工业园区和单体建筑的规划人员，以直观方式建立能源系统方案，完成设备选型、容量配置与运行调度分析，并获得可用于方案比较和决策的结果。

## 核心用户闭环

1. 建立能源系统模型。
2. 配置设备、能源需求和外部条件。
3. 检查模型完整性并获得可理解的修正建议。
4. 执行规划计算。
5. 查看技术、经济和环境结果。
6. 对比方案并支持规划决策。

## 首阶段目标

- 支持小型工业园区和单体建筑场景。
- 支持电负荷、光伏、储能和电网组成的基础系统。
- 支持设备选型、容量配置和运行调度的联合分析。
- 输出成本、能源利用和环境影响等关键指标。
- 对无效或不可计算的模型给出明确、可操作的诊断。
- 提供完整、可重复验证的端到端使用流程。

## 成功标准

- 用户能够独立完成从建模到结果查看的完整流程。
- 相同输入能够得到稳定、可复现的计算结果。
- 关键约束、计算假设和指标含义对用户透明。
- 错误信息能够定位问题并指导修正。
- 不同方案能够使用一致指标进行比较。

## 当前状态

重新规划中。技术方案、架构、范围边界和实施路线尚未确定。
